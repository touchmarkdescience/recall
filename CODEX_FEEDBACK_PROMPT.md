# Codex task: mobile UI and voice follow-up corrections

Update the existing Recall app. Keep its light visual system and current manual-entry workflow, while making voice capture the fast path. Work in the existing Next.js PWA; do not replace the project or add unrelated features.

1. **Mobile layout:** Fix iPhone input-focus zoom across all forms by using mobile input/select/textarea font sizes of at least 16px. Do not disable user zoom. Make every screen feel like a native iPhone/Android app: safe-area spacing, compact content, large touch targets, consistent bottom navigation, and minimal scrolling.
2. **Voice entry:** The bottom mic opens capture. Improve transcription/contact extraction so a spoken person's name is retained. The name is optional: users must be able to save a follow-up using only action text, without inventing a contact. Update validation, storage, dashboard, calendar, and Sheet export to support contact-less actions. If a name is detected, show it for correction before saving.
3. **Date/time review:** If transcription yields one clear due date and time, show the extracted value in a compact summary and keep the picker collapsed. Offer an **Edit** control. If no date/time is clear, allow optional manual selection. Never silently choose between conflicting spoken times; ask the user to confirm one.
4. **Extraction example:** For “Tomorrow I am meeting Sujay for a demo about startup product; remind me at 1:00 p.m. — or the meeting is at 4:00 p.m.” identify **Sujay** as the person, **startup product** as the topic, **tomorrow** as the day, and **1:00 p.m. versus 4:00 p.m.** as ambiguous times requiring confirmation. Do not create a person named “startup product.”
5. **PWA/push:** Verify installability and background Web Push on iPhone Home Screen and Android, including permission and subscription flows. Keep account-owned reminders and the existing five-minute scheduler. Report what was verified on real devices versus what remains untested.

Acceptance checks: no input-focus zoom on iPhone; mic opens capture; action-only voice entry saves; the example extracts the correct person/topic and requests time confirmation; a single clear spoken time skips the expanded picker; manual entry still works; install/push behavior is tested or explicitly marked unverified. Run typecheck/build and summarize changed files and remaining limits.
