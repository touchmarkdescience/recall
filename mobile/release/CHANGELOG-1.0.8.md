# Recall 1.0.8 (Android build 10)

Includes the fixes in CHANGELOG-1.0.7.md plus the final reminder-picker copy changes:

- Custom time: short title with “Choose date and time” below it.
- Fifteen-minute row shortened to “15 min before”; it retains the separate timed-action save path that avoids the existing offset constraint.
- The last two options were 1 hour and 1 day, not duplicate hours. They now read “60 minutes before” and “24 hours before (1 day).” Values remain 60 and 1440 minutes respectively.

No reminder scheduling, storage, API or permissions changes in this final copy adjustment. Full original-note display still requires merging the accompanying backend changes from the 1.0.7 work.
